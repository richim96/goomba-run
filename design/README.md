# Game design

A snapshot of the **Goomba Run Art** design canvas on claude.ai (https://claude.ai/artifact/GCQm1iKcD6XzWB4MwiihNA, private to the owner's account). The canvas is where the art is reviewed; this folder keeps a copy of it in the repo.

- `canvas.json`, `boards/*.dc.html`: the canvas's own files (Claude Design format). They render only on claude.ai; image paths point at `images/`.
- `images/`: every picture the boards show, named by their asset id on the canvas.
- Keep it in sync: whenever a board changes, copy its files and new images here in the same change.
